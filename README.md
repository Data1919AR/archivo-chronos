# Archivo Chronos

**Una producción de fans de Star Trek · Gratuita · Sin ánimo de lucro · No oficial**

Archivo Chronos es un calendario de Adviento interactivo hecho por un fan para otros fans: 24 transmisiones perdidas de la USS Chronos, una cada día del 1 al 24 de diciembre, y el Protocolo Omega el 25.

Su única finalidad es la difusión entre aficionados. No se vende, no tiene anuncios, no pide donaciones y no genera ningún ingreso. Se puede ver y compartir libremente el enlace; no está permitido ningún uso comercial de esta obra ni de sus contenidos.
